# Answers of the forum's app API, as test data

`forum_v2_*.json` (forum page, `schema: 2`) and `thread_v3_*.json` (thread page, `schema: 3`) are real answers of the
`tsdmapp` plugin, fetched from a test forum and scrubbed. They are regenerated by a tool kept with the plugin, not by hand:
the tool fetches every case again, drops `document`/`head`, rewrites the test forum's host and name, and normalizes the
fields that change on every request so the tests can pin them:

- `formhash` → `f1f2f3f4`
- `reply.posttime` → `1700000000`
- `thread.views` → `100`

`forum_v2_fid2.json` and `thread_v3_plain.json` carry a deliberate garbage `document`: the tests prove the structured
path never reads it. `forum_v2_fid29_pending.json` is hand-written (the pending-application message). Everything else must
not be edited by hand; change the plugin or the tool instead.
